The Mac app can now open `.md` files when you double-click them in Finder.

## What changed

- **It asks once.** After you sign in for the first time, the app asks whether to make Markbase the default app for markdown files. Choose **Set as default**, or close the prompt to skip it. It won't ask again.
- **Double-click to edit.** A double-clicked `.md` file opens in Markbase as a document you can edit. Changes are saved back to the same file.
- **Vault files stay synced.** If the file is inside a synced vault, the synced document opens instead of a separate copy.
- **Editor shortcuts.** ⌘A selects the whole document and ⌘B makes text bold. ⌘\ shows and hides the sidebar.

## Changing it later

The default app is a Finder setting, so you can switch any time.

1. In Finder, select a `.md` file and choose **Get Info**.
2. Pick an app under **Open with**.
3. Click **Change All**.
