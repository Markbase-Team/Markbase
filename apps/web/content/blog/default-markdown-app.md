The Mac app can now open `.md` files when you double-click them in Finder.

## What changed

- After you sign in for the first time, the app asks once whether to make Markbase the default app for markdown files. Choose **Set as default**, or close the prompt to skip it. It won't ask again.
- A double-clicked `.md` file opens in Markbase as a document you can edit. Changes are saved back to the same file.
- If the file is inside a synced vault, the synced document opens instead of a separate copy.
- In the editor, ⌘A now selects the whole document and ⌘B makes text bold. ⌘\ shows and hides the sidebar.

## Changing it later

In Finder, select a `.md` file, choose **Get Info**, pick an app under **Open with**, then click **Change All**.
