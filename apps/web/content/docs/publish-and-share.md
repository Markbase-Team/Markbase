# Publish and share

Some documents are for the team; some are for everyone. Both start from the
same document.

## Share with people

Use **Share** on a document to add people by address as viewers, commenters
or editors. An editor's changes merge into the document like yours. A shared
document also reaches the person's machine, in their
[Shared Vault](/docs/sharing), if they use the desktop app or the CLI.

## Publish a public link

A public link lets anyone read the document without an account: a living spec
a client can follow, a changelog, a guide. The page always shows the current
version, so there is nothing to re-export when the document changes.

## Keep it current

Because the published page is the document itself, the agent that updates the
document in your repository updates what your readers see. There is no second
copy to forget.
